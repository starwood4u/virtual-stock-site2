업무요청(WR) 조회 API

ONVEST 서브시스템 w3 — 업무요청 데이터를 JSON으로 제공합니다.

엔드포인트

GET /api/work-requests 전체 조회

GET /api/work-requests?requestId={requestId} 업무요청 단건 조회 (workRequests)

GET /api/work-requests?requestDpId={requestDpId} 개발계획 단건 조회 (developmentPlans)

응답은 Content-Type: application/json이며 CORS가 허용되어 외부 도메인에서도 호출할 수 있습니다. 대상을 찾지 못하면 404와 {"error": "..."}를 반환합니다. (로컬 개발 서버에서는 /w3 접두사가 붙어 /w3/api/work-requests로 접근합니다.)

응답 구조

응답은 workRequests(업무요청)와 developmentPlans(개발계획) 두 배열로 구성됩니다. 개발계획은 requestId로 상위 업무요청과 연결됩니다.

workRequests (업무요청) 필드

필드 설명
requestId업무요청 번호, WRxxxx 형태 (예: WR0201)
title업무요청 제목
requester업무 요청자 이름
requestDate요청일 (YYYY-MM-DD)
status진행 상태 (완료 / 진행중 / 접수)
relatedSystem관련 시스템명
description상세 설명

developmentPlans (개발계획) 필드

필드 설명
requestDpId개발계획 번호, WRxxxx-DPx 형태 (예: WR0201-DP1)
requestId상위 업무요청 번호 (workRequests.requestId 참조)
title개발계획 제목
developer개발 업무 담당자
tasks개발 업무 목록 (배열)
status진행 상태 (완료 / 진행중 / 접수)
registerDate개발계획 등록일 (YYYY-MM-DD)
relatedPage관련 화면 경로
